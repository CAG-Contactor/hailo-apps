# Initial Concept
High performance AI applications for Hailo accelerators, including GStreamer pipelines, GenAI assistants, and standalone C++/Python apps.

# Product Overview

**Hailo-Apps** is a monorepo offering a robust suite of high-performance AI applications designed exclusively for Hailo AI accelerators (Hailo-8, Hailo-8L, and Hailo-10H). The project serves as a comprehensive hub for AI-powered development, demonstrating real-time machine learning workflows.

## Key Features
- **GStreamer Pipeline Apps:** Pre-configured and optimized real-time video processing pipelines for tasks like object detection, pose estimation, and instance segmentation.
- **GenAI Assistants:** Large Language Model (LLM) and Vision-Language Model (VLM) applications tailored for Hailo-10H, including voice and speech capabilities.
- **Standalone Apps:** Minimalist, framework-independent C++ and Python applications demonstrating direct HailoRT API usage.
- **AI-Powered Development:** Integrated AI coding agents to autonomously build, validate, and execute custom applications.

## Target Audience
- **AI Developers & Engineers:** Building and deploying AI models directly onto Hailo edge devices.
- **System Integrators:** Integrating real-time video and audio analytics into IoT, automotive, or industrial edge hardware.

## Supported Platforms
- **Hardware:** Hailo-8, Hailo-8L, Hailo-10H accelerators.
- **OS/Environments:** Raspberry Pi 5, Ubuntu (x86_64), and Windows.
