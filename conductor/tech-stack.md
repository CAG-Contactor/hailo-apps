# Technology Stack

## Languages
- **Python (3.10+):** Primary language for application logic, GenAI integration, and testing.
- **C++:** Used for performance-critical standalone applications and custom GStreamer elements.

## Frameworks & Libraries
- **HailoRT:** The core runtime library for interfacing with Hailo AI accelerators.
- **GStreamer:** Primary framework for constructing robust, real-time video processing pipelines.
- **OpenCV & NumPy:** Standard libraries for image manipulation and array operations.
- **Loguru:** Logging utility for Python applications.

## Development & Tooling
- **Testing:** `pytest` is used for unit and integration testing across the Python codebase.
- **Linting & Formatting:** `ruff` provides fast Python linting and formatting.
- **Pre-commit Hooks:** Used to ensure code quality standards before commits are finalized.
